# Street Talk

Talk to Night City's people. Actually talk — type what you want, and they
answer in character, generated by an AI model. Run it **fully on your own
machine** — no API key, no account, nothing leaves your PC — or point it at a
cloud provider like OpenRouter if you'd rather not run a model yourself.

Shopkeepers, ripperdocs, bartenders and other NPCs anchored to a place
**remember you between conversations**. Come back a week later and they know who
you are.

> Written with Claude (Opus 5 and Fable 5, high reasoning effort) as the
> implementation partner: it wrote the code and dug the APIs out of decompiled
> game sources, under my direction. The design, the priorities, every judgment
> call about what belongs in a Cyberpunk mod, and all of the testing that found
> the real bugs are mine. Every engine API used here was verified against the
> game's own scripts before it shipped — the comments in the source name the
> file and line, and say what field-testing proved wrong.

## ⚠️ Read this first

**1. Using a LOCAL model? You must add a launch option or the mod will appear
completely dead.** Cloud users (OpenRouter) skip this entirely — HTTPS needs
no launch options.

Right-click Cyberpunk 2077 in Steam → Properties → Launch Options:

```
%command% -no-tls
```

RedHttpClient (a dependency) refuses plain `http://` requests unless the game
is launched with `-no-tls`. Without it, every request to a local server fails
instantly with no error message and the mod looks broken. This is the single
most common local-setup problem.

GOG/Epic users: add `-no-tls` to the game's own launch arguments the same way.

**2. This mod can affect your save, permanently.**

Conversations lead to NPCs doing things: following you, getting in your car,
handing over or taking eddies, walking off — and, if you turn Violence on,
shooting whoever you point them at. That is a real fight with real deaths, and
the mod does not second-guess it: a companion who is asked to shoot a bystander
will shoot a bystander. **If a quest character dies, that quest is gone.**

The bar is deliberately low. A model that plays its part will act on what you
ask, and a small model sometimes acts on what you did not quite ask. That is
the price of NPCs who can actually do things, and the controls are yours: NPC
Actions and Violence are separate switches in Mod Settings, both off until you
turn them on, and `/reset` puts the person in front of you back to normal.

It is not a cosmetic mod. **Back up your saves before you use it**, or play on
a save you don't mind losing. Saves live in:

```
%USERPROFILE%\Saved Games\CD Projekt Red\Cyberpunk 2077\
```

## Requirements

- Cyberpunk 2077 (tested on 2.31). Phantom Liberty is optional: with it,
  the expansion's characters get voices, bios and quest awareness like
  everyone else; without it, nothing looks for it.
- [RED4ext](https://www.nexusmods.com/cyberpunk2077/mods/2380)
- [redscript](https://www.nexusmods.com/cyberpunk2077/mods/1511)
- [Codeware](https://www.nexusmods.com/cyberpunk2077/mods/7780)
- **RedHttpClient 0.7.1 or newer** — ⚠️ **get this from
  [GitHub releases](https://github.com/rayshader/cp2077-red-httpclient/releases),
  not Nexus.** The Nexus page may still serve 0.7.0, and 0.7.0 has **no
  `-no-tls` support at all** — the flag simply does not exist in that build, so
  every request fails silently no matter what you do. Check your version in
  `red4ext\logs\red4ext-*.log`; it prints on startup.
- [RedData](https://www.nexusmods.com/cyberpunk2077/mods/16948)
- [RedFileSystem](https://www.nexusmods.com/cyberpunk2077/mods/13378)
- [Mod Settings](https://www.nexusmods.com/cyberpunk2077/mods/4885)

Optional, each unlocking a feature:

- [Audioware](https://www.nexusmods.com/cyberpunk2077/mods/12001) - spoken replies (TTS)
- [Appearance Menu Mod](https://www.nexusmods.com/cyberpunk2077/mods/790) - NPCs
  gesture while they speak (the talk animations ride on AMM's anim entity; without
  AMM the feature quietly does nothing). Worth having for a second reason: AMM
  can make an NPC follow or stop following by hand, which is the manual way out
  if a companion ends up in a state this mod cannot fix.

If the game shows a "REDScript compilation failed" popup listing lots of mods,
you are missing one of these. The list in that popup is misleading — everything
compiles as one unit, so one missing dependency takes down every script mod at
once. Check `r6\logs\redscript_rCURRENT.log`; the **first** error names the real
cause.

## You also need an AI model — two ways

### Quickest: cloud (OpenRouter)

Pick **OpenRouter** in Mod Settings → Server, then put your API key and a
model id (e.g. `meta-llama/llama-3.3-70b-instruct`) in
`r6\scripts\StreetTalk\StreetTalkConfig.reds`. No launch options, no
downloads, no hardware requirements. The honest tradeoff: your conversations
go to their servers — if that bothers you, go local.

### Fully local and private

The mod talks to any **OpenAI-compatible** server. It does not ship a model —
they're several gigabytes and carry their own licenses. You download one once
and point the mod at it.

### Easiest local setup

1. Install [LM Studio](https://lmstudio.ai) or [Ollama](https://ollama.com)
2. Download a model (see below)
3. Start the server
4. In Mod Settings → Street Talk → **Server**, pick the one you're running

That's it. The address is filled in for you.

### Recommended model

**Dan's Personality Engine 7B, Q5_K_M** — about 4.8 GB.
Search for `7b-m-dans-personalityengine-v1.2.1-rc-5-GGUF` on Hugging Face.

It's tuned for character work rather than general assistance, which is what
this needs. Any instruct model works; character-tuned models are noticeably
better at not sounding like a helpful chatbot in a trenchcoat.

### Hardware

The model runs **alongside the game**, sharing your GPU.

| Your VRAM | What to do |
|---|---|
| **16 GB+** | Comfortable. ~5 GB model + game, plenty of margin. Recommended. |
| **12 GB** | Fine at 1080p/1440p. Watch your texture settings. |
| **8 GB** | Tight. Only if the game itself fits in ~3 GB — realistically low settings, no ray tracing. Consider a smaller model (Q4_K_M, ~4.1 GB). |
| **Under 8 GB** | Run the model on your CPU, or on a second machine, and point "Custom" at it. |

Ray tracing roughly doubles the game's VRAM use. If you run RT, budget for it.

Reference numbers on a 16 GB card with the game running and RT on:

```
game with ray tracing   ~9.0 GB
model + cache           ~5.6 GB
                       ────────
                       ~14.6 GB of 16 GB
```

Replies land in about a second. If yours are much slower, the model is probably
spilling into system RAM — use a smaller quantisation.

## Using it

Look at an NPC. If they can talk, a small **[R] talk** prompt appears below
the crosshair. Press **R** (rebindable — Mod Settings → Street Talk →
Controls):

- The chat opens on the left with the text box already focused. Type, press
  **ENTER** to send.
- Press **ENTER on an empty box** to step out of the text box. While the box
  is focused, letter keys type into it — including the talk key.
- With the box unfocused: the talk key **closes** the chat, **DELETE** wipes
  the conversation and starts it over, and the **arrow keys** scroll back
  through the conversation.
- Reopening the chat on the same NPC resumes where you left off. Community
  NPCs also remember you across game sessions.

The game keeps running — you can move around mid-conversation. One thing to
know: if the game itself also binds your talk key (R is refuel/reload in some
setups, and might be your interact key), the game still does its thing too.
Keys can't be reserved from a mod; pick a free key in Controls if the overlap
bothers you.

## How it works

Functionally: look at anyone, press R, type. They answer in character, out
loud, and remember. No character packs, no hand-added NPC list — if the game
can spawn them, you can talk to them.

Technically, there is no authored content in this mod at all. The character
card is assembled **live at chat-open** from what the game itself knows about
the person in front of you:

- **Who they are** — their name resolved the way the scanner resolves it
  (including quest-driven name reveals), civilian/ganger/kid classification,
  gang affiliation from their character record, and for crowd NPCs a
  description derived from their actual appearance asset.
- **Where and when** — district and in-game hour, read live.
- **What they know** — world context gated on your actual quest facts (the
  city talks about what has happened in *your* save), per-character
  relationship context for story characters, and whether they know V at all:
  strangers don't get told your name.
- **How they talk** — up to eight of the character's real spoken lines,
  harvested from your own archives by pairing voiceover files with subtitle
  text, fed in as few-shot examples so a 7B stops sounding like a helpful
  chatbot in a trenchcoat.
- **What they remember** — a persistent per-character memory: the model
  summarizes each conversation into the NPC's own recollection, which feeds
  every future chat. Identity is keyed on stable record hashes, so the same
  bartender is the same bartender next week.

The voice pipeline is the same philosophy: the first time a character speaks,
their VO lines are located in your archives by speaker name, scored for
cleanliness, decoded, and assembled into a reference clip that XTTS-v2 clones
locally on your CPU — sentence-chunked so text appears on screen as the words
are spoken. Characters without unique VO get a real archive voice bank
matched on gender and faction and varied by their look. Every byte of
character data and audio comes from the game install you already own; the
mod ships none of it.

## Privacy

Your conversations are not written down anywhere except where the feature
needs them:

- **One optional feature touches the internet, and it is off by default.**
  *Character Lookup* fetches a named character's intro from the Cyberpunk wiki
  so they know who they are. With it off, nothing is sent anywhere. With it on,
  the only thing transmitted is a character's name — the same request your
  browser makes opening that page. Wiki text is fetched by your machine and
  cached locally; none of it ships with the mod.
- **Nothing is logged.** With **Debug Log** off (the default) the mod writes
  no log file at all. Even with it on, replies are logged as a character
  count, never as text.
- **The voice server logs no conversation content either** — only structural
  lines (which voice, which slot, whether an animation matched). If you are
  extending the animation thesaurus and want the wording in the log, opt in
  with `STREETTALK_LOG_CONTENT=1`.
- **Saved conversations** live in `r6\storages\StreetTalk\` on your machine,
  because resuming a conversation later is the whole point. Delete a file to
  erase that character's history, or use **Forget Everyone** in Mod Settings.
- Local model + local voice = nothing leaves your PC at all. Choose
  OpenRouter and your messages go to their servers instead; that is the
  tradeoff and it is yours to make.

## Settings

All in Mod Settings → **Street Talk**.

| Setting | What it does |
|---|---|
| **Enabled** | Master on/off |
| **Server** | Local presets or OpenRouter (cloud). Presets fill in the address |
| **Talk Key** | Opens/closes the chat. Default R |
| **Reset Key** | Wipes the current conversation. Default DELETE |
| **Reply Length** | Max tokens per reply. 120 suits spoken dialogue |
| **Temperature** | Higher = more unpredictable. 1.0 is a good default |
| **Context Size** | Your server's context window in tokens. Match your `-c` / context length setting |
| **Memory Summaries** | On chat close, the model updates what the NPC remembers about you |
| **NPC Actions** | NPCs can follow you, stop, or greet you when the conversation calls for it |
| **Community NPCs** | Shopkeepers etc. — these remember you |
| **Crowd NPCs** | Random pedestrians — these *cannot* remember you (see below) |
| **Forget Everyone** | Erases all NPC memory. One-shot; flips itself back off |
| **Talking Gestures** | NPCs gesture while their reply plays. Needs AMM installed |
| **Debug Log** | Troubleshooting only. Off by default — with it off the mod writes no log lines and no log file at all |

Advanced users: `r6\scripts\StreetTalk\StreetTalkConfig.reds` holds the custom
URL, model name, an optional API key, and a house-style prompt applied to every
character.

## Voice (experimental)

NPCs speak their replies aloud, in a cloned approximation of their own
voice, from where they're standing. Off by default; turn on **Spoken
Replies (TTS)** in Mod Settings.

**Setup is one line — the same Launch Options line you may already have.**
There is nothing to run, ever; the Play button does everything.

Windows — the download already puts the launcher at
`<game>\tools\StreetTalk\`, so just add this line:

```
"C:\...\Cyberpunk 2077\tools\StreetTalk\streettalk-launch.bat" %command% -no-tls
```

Linux/Proton:

```
"/path/to/Cyberpunk 2077/tools/StreetTalk/streettalk-launch.sh" %command% -no-tls
```

On Linux the two archive tools (WolvenKit CLI, vgmstream) are not fetched
for you — point at your own copies with `STREETTALK_WOLVENKIT` /
`STREETTALK_VGMSTREAM`, or skip them and NPCs use built-in voices.

First launch bootstraps everything in the background (a private Python, the
voice model, the extraction tools — all ordinary released tools fetched
from their official sources by a short script you can read; nothing
packaged, nothing hidden, nothing installed system-wide). Every launch
after that: game starts, voice quietly starts with it, both stop together.

**Voice is always generated locally**, on your CPU, cloned from your own
game files — regardless of whether your *text* comes from a local model or
a cloud provider. So: cloud text without voice needs no launch options at
all; anyone who wants voice adds the launcher line (its `-no-tls` part only
matters for local models and is harmless otherwise).

One-time pieces:

1. [Audioware](https://www.nexusmods.com/cyberpunk2077/mods/12001) —
   optional dependency; without it the mod is text-only.
2. Enable **Spoken Replies (TTS)** in Mod Settings.

While a reply is being spoken, the game's own dialogue volume is briefly
lowered so chatty NPCs (street preachers, phone talkers) don't talk over
their own reply, and restored the moment the line ends. With AMM installed,
the NPC also gestures while speaking.

**Voices are automatic.** The first time you talk to a named character, the
server extracts that character's real voice lines from *your own* game
archives, builds a reference clip, and clones their actual voice — locally,
one-time, cached from then on. Nothing is shipped or uploaded; the voices
come from the game you own. Crowd NPCs get voices too: the server picks a
matching archive voice bank (right gender, right faction where possible,
varied by the NPC's actual look, stable per person) and clones that — so two
pedestrians don't sound like the same person. Any clip you drop in
`server/voices/<Name>.wav` overrides the automatic one.

Text always appears immediately; the spoken line follows a few seconds later
(synthesis runs on CPU so it doesn't fight the game for GPU). Voices are
cloned zero-shot from your clips, on your machine — nothing ships, nothing
uploads. First-ever spoken line downloads the XTTS model (~2 GB) once.

When a character speaks for the first time ever, the chat shows
**learning their voice...** for the few seconds it takes to build their
voice from your archives — after that they're instant, forever.

## Why crowd NPCs don't remember you

Cyberpunk has two kinds of NPC:

- **Community NPCs** — shopkeepers, ripperdocs, bartenders, anyone standing in a
  fixed spot. The game gives them stable identities, so this mod can remember
  them permanently.
- **Crowd NPCs** — pedestrians. The engine pools and recycles them, and their
  names are generated randomly at spawn. The same face can come back with a
  different name; two identical people can walk past you. There is no stable
  identity to attach a memory to.

So crowd conversations are one-off by design, and they're off by default. This
isn't a limitation the mod can engineer around — it's how the game spawns
crowds.

## Troubleshooting

**No "[R] talk" prompt appears on anyone.**
Check **Enabled** in Mod Settings, and that you're looking at a living,
non-hostile NPC. Crowd pedestrians only show it if **Crowd NPCs** is on.

**The chat opens but replies never arrive.**
You almost certainly missed `-no-tls`. See the top of this file.

**"REDScript compilation failed" listing many mods.**
A missing dependency. Read `r6\logs\redscript_rCURRENT.log` and find the *first*
error.

**Replies are very slow.**
The model doesn't fit in VRAM and is spilling to system RAM. Use a smaller
quantisation, or lower the game's texture settings.

**The game stutters while an NPC replies.**
Expected — generation shares your GPU with the game. Lower **Reply Length**.

**NPCs reply with empty messages.**
You're running a reasoning model. Start your server with reasoning disabled
(`--reasoning off` on llama.cpp) or use a non-reasoning model. Reasoning models
put their output in a separate field this mod doesn't read.

## AI disclosure

This mod uses AI at runtime, and ships none of its output:

- **Dialogue text** is generated live by whatever language model you connect
  (your local server, or a cloud provider you choose).
- **Spoken replies** are synthesized live on your own CPU by the XTTS-v2
  model, cloning voices from lines already inside **your own** game archives.
  No audio is bundled, uploaded, or distributed - the voices never leave your
  machine, and nothing plays without you enabling TTS.
- The download itself contains **no AI-generated content**, no model weights,
  and no game assets: it is hand-written scripts plus a readable Python
  server.

The XTTS-v2 voice model is downloaded on first use directly from its
publisher and is licensed under the
[Coqui Public Model License](https://coqui.ai/cpml) (non-commercial use).
